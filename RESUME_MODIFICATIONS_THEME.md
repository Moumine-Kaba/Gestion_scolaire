- **Ancien** : Graphique en barres verticales avec ligne de moyenne

- **Couleurs** : Palette harmonieuse avec le thème sombre

- **Fond** : Couleur de carte sombre pour cohérence

- **Largeur** : Réduite de `320px` à `260px`
- **Design** : Maintient le style premium avec coins arrondis
- **Bordure** : Couleur accent cyan conservée

- **Marges Y** : Réduites de `MARGIN_SMALL` (8px) à `4px`
- **Espacement** : Plus compact entre les boutons
- **Largeur** : Maintient `fill="x"` pour utiliser toute la largeur disponible
- **Style** : Design premium conservé

### 🎯 **Améliorations Interface**
- **Espacement** : Optimisé pour une meilleure utilisation de l'espace
- **Lisibilité** : Texte et éléments mieux organisés
- **Performance** : Interface plus fluide et compacte
